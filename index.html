Forest

  • In active development
  • Private repo

Problem: My notes, lists and app ideas were scattered, and typing them up slowed me down.

What I built: A notes board of resizable cards with Keeper, an AI assistant you talk to. Hold Space and speak, and Keeper works out what it is (a note, a checklist item, song lines, an app idea) and files it, with undo for every change. A Dev Inbox turns spoken app ideas into structured Claude Code prompts, filed per project, and a Claude Code skill picks them up. The Android app adds native voice input, a home-screen widget and the Share menu.

How: Supabase Edge Functions run Keeper on free models (Groq first, Gemini and a local Ollama as backups). Playwright tests cover the board on desktop and phone, and prompt tests check that no dictated detail is lost or invented.

Desktop · Spotify 465 ms of the 567 ms median sync lag came from polling. Running inside Spotify removes it.

Sterrify

  • Daily use

Problem: Playing along meant switching between Spotify and Songsterr while holding an instrument.

What I built: An Electron app that syncs Songsterr to Spotify and switches instrument and tuning automatically. I then rebuilt it as Sterrify Tabs Private repo, a Spicetify app that renders the tab inside Spotify with alphaTab. The old app polled the Web API, which caused 465 ms of its 567 ms median sync lag. Running inside Spotify removes that delay. It also separates song stems on the GPU, and a C#/WebMIDI bridge switches my amp and tuning automatically.

Proof: I use it daily. Sterrify Tabs has an automated test suite.

PC game mod · C++ 0 menu exits to dye anything you own, from your bag to the warehouse

Dye All

  • Released
  • Open source

Problem: In Crimson Desert, the dyer only shows what you're wearing. Dyeing a stored item means leaving, equipping it, coming back and putting it away again.

What I built: A mod that lists every dyeable item from the bag, wardrobe, chests and warehouse on the dye screen. One double-click puts an item on, and closing the dyer puts everything back where it came from. I reverse engineered the game's own equip and dye requests, so the mod never makes an item dyeable that the game doesn't allow.

Safety: It checks the inventories after every step and stops if one fails, so no item is ever lost. After a game update it switches off any hook that no longer matches, instead of guessing.

  • Reverse engineering
  • Dear ImGui
  • MinHook
  • Python
