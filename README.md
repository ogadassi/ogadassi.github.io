# Ohad Gadassi: Portfolio (Figma variant 1)

A redesign of the portfolio after the [Portfolio (Community) Figma file](https://www.figma.com/design/QamGTXy4E57obJc9MUppEX/Portfoloio--Community-?node-id=0-1), recolored to a cyan-green → forest-green palette. Same content and facts as `main`.

Live (main design): https://ogadassi.github.io

## How it works

- No build step. The site is `index.html`, `style.css`, `favicon.svg` and the `assets/` folder.
- Fonts (Inter, DM Sans, IBM Plex Mono) load from Google Fonts. Skill logos load from Devicon on jsDelivr.
- Project cards have no screenshots, so each card's image slot shows one real number from that project instead.
- This branch is checked out as a git worktree next to the main repo, so both designs can be served side by side.
