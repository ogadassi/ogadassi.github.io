# Ohad Gadassi: Portfolio

A basic personal portfolio page, plain HTML and CSS. Built from `PROMPT.md` as a workshop exercise.

Live: https://ogadassi.github.io

## How it works

- No build step. The site is just `index.html`, `style.css` and the `assets/` folder.
- To preview, open `index.html` in a browser.
- Pushing to `main` deploys it through GitHub Pages, usually within a minute or two.
