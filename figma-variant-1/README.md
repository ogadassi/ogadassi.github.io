# Figma variant 1

A redesign of the portfolio after the [Portfolio (Community) Figma file](https://www.figma.com/design/QamGTXy4E57obJc9MUppEX/Portfoloio--Community-?node-id=0-1), recolored to a cyan-green → forest-green palette. Same content and facts as the main `index.html`.

- Layout taken from the Figma frames: scrolling name over the portrait, floating dock nav, big-type section heads, 2-column project cards, dark bento cards for skills, the "Let's talk" contact block and the giant-name footer.
- Project cards have no screenshots, so each card's image slot shows one real number from that project instead.
- Fonts (Inter, DM Sans, IBM Plex Mono) come from Google Fonts. Skill logos come from Devicon on jsDelivr.
- To preview, open `figma-variant-1/index.html` in a browser. The page is `noindex` and its canonical URL points at the live site.
